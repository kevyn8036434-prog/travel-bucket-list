# travel-bucket-list

Um site moderno de viagens para listar destinos e planejar futuras aventuras.

## Como abrir

Basta abrir o arquivo `index.html` no navegador.

## Estrutura

- `index.html` — página principal
- `styles.css` — design visual
- `script.js` — filtros de categoria

## Objetivo

Criar uma landing page inspirada em viagens, com destinos, ideias e layout responsivo.
